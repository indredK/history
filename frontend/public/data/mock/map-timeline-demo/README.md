# Map Timeline Demo Mock

这是一套专门给“地图页时间轴联动”准备的近现代演示数据，目标不是做全量历史资料，而是支撑下面三类交互：

1. 点击朝代，地图切到该朝代默认疆域。
2. 点击事件，事件以时间段形式被选中，地图默认落在事件起点，并可在事件时间段内演变。
3. 点击播放，地图按年份推进；若当前选中事件，则优先在事件时间段内推进。

## 文件说明

- `dynasties.json`
  - 地图页第一行朝代数据。
  - 这里只保留近现代演示需要的 4 个阶段：晚清、北洋政府、国民政府、中华人民共和国。

- `events.json`
  - 地图页第二行事件数据。
  - 事件字段兼容现有 `events.json` 风格，同时额外提供：
    - `map_focus_start_year`
    - `map_focus_end_year`
    - `map_location_hints`
    - `dynasty_id`
  - 这些字段用于明确表达“事件是时间段，不是单点”。

- `places.json`
  - 事件地点与区域锚点。
  - 同时包含城市点位和区域代表点，例如：
    - `武汉`
    - `长江流域`
    - `华北地区`
    - `全国各地`

- `boundary-mappings.json`
  - 按年份映射到具体疆域文件。
  - 同一个朝代可以对应多个地图演变阶段，例如中华人民共和国分成：
    - `prc_1949`
    - `prc_1951`
    - `prc_1997`
    - `prc_1999`

- `*.geojson`
  - 粗粒度 mock 疆域。
  - 用于 UI 演示，不代表严格历史考据结论。

## 推荐消费方式

后续写代码时，建议在“地图联动演示模式”下直接加载这套数据，而不是先强行复用全站通用数据：

1. 第一行朝代：`dynasties.json`
2. 第二行事件：`events.json`
3. 地点解析：`places.json`
4. 年份 -> 疆域：`boundary-mappings.json + *.geojson`

## 事件时间段语义

当事件被选中时：

- 默认地图年份 = `map_focus_start_year`
- 事件可演变范围 = `[map_focus_start_year, map_focus_end_year]`
- 如果播放按钮被点击：
  - 优先在这个事件范围内推进年份

例如：

- `辛亥革命`：1911 -> 1912，可演示从晚清切到北洋政府。
- `北伐战争`：1926 -> 1928，可演示从北洋政府切到国民政府。
- `解放战争`：1946 -> 1949，可演示从国民政府切到中华人民共和国。
- `香港回归进程`：1984 -> 1997，可演示 1997 的主权节点。
